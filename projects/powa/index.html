RoleSenior Product Designer (UX/UI)
ClientPOWA
Year2026
ScopeUX/UI, Design system, Visual language
Project overview
A first MVP for an enterprise product spanning agentic delivery and intent structuring

I joined POWA at an early stage as a Senior UX/UI Designer, with the goal of designing a fully functional first MVP for an enterprise product spanning agentic delivery and intent structuring.

As a founding designer, I set up the design process from scratch, running it end-to-end and establishing practices to integrate AI into the design workflow.

Discovery

Mapped user journeys and defined the information architecture of the core workflows

Role and process
Discover

User journeys, information architecture and design workshops with the cofounder and product owner.

Prototype

Core flows, wireframes and interactive prototypes for web and mobile, iterated directly in code with Claude.

Build

The design system and UI kit from scratch, implemented as components, in Figma and Claude.

Shape

The look and feel, with the brand designer, translated into UI for dark and light modes.
